## 3. Data Sources

For this project, I will mainly use two free F1 data sources.

### FastF1

FastF1 will be my main source. It is a Python library that gives access to F1 race and timing data.

I plan to use it for:
- Race results
- Driver positions
- Lap times
- Pit stops
- Track status and Safety Car information

https://docs.fastf1.dev/

### Jolpica F1 API

I will also use the Jolpica F1 API to get some of the race information and check my data when needed.

I plan to use it for:
- Race results
- Driver and team information
- Starting grid positions
- Qualifying results
- Lap data
- Pit stops

https://api.jolpi.ca/docs/

### Data Range

I am planning to use F1 race data from **2018–2026**. I may change the range later depending on the data I can collect and how complete it is.
